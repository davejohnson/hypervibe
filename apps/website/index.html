02 / guardrails

What Hypervibe won’t do.

Codex or Claude can ship the app, but they can’t create extras you didn’t review, hide a failed check, or reach outside the change list.

Use a saved connection

Every change goes through the hosting accounts you connected to Hypervibe.

Stop when a check fails

A timeout or permission error stops the job. It never gets treated as “nothing exists.”

Make only the listed changes

Setting up an app can’t quietly add a database or remove something else.

Don’t print secrets

Passwords and API keys stay out of plans, logs, snapshots, and command results.
