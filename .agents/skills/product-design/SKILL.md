# Hypervibe product design

Read and follow [the shared design workflow](../../shared/product-design/SKILL.md).
Paths below are relative to the repository root.

Read `.agents/project/product-design.md` for audience, defaults and import flow.
Preserve `.agents/project/workflow.md` command boundaries. Credential prompts and
handoffs also require `.agents/project/credentials.md`; resource decisions use
`ARCHITECTURE.md` and `.agents/project/lifecycle.md`. Do not make a smoother
interface by bypassing plan authority, exact confirmation or destination scope.
For native interfaces use `.agents/project/native.md`.

Verify the rendered interface or actual human command output alongside machine
contracts; passing serialized API tests does not prove understandable UX.
